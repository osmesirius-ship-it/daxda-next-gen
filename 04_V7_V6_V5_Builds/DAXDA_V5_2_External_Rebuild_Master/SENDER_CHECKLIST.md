# Sender Checklist

Before sending a reviewer package:

- [ ] Insert all five original source artifacts into `SOURCE_FILES/`.
- [ ] Run `python verify_package.py`.
- [ ] Confirm all hashes show `MATCH`.
- [ ] Do not alter reviewer instructions.
- [ ] Assign a different package to each reviewer.
- [ ] Do not coach reviewers during the first run.
- [ ] Ask reviewers to return the complete package, not only screenshots.
- [ ] Preserve returned ZIPs unchanged.
- [ ] Compare results only after all three reviewers have submitted.
- [ ] Describe the outcome as reproducibility evidence, not independent validation.
